# Crypto Utils v0.2（核心功能完整化）

> v0.2 是平台的第二个版本，目标是**核心功能完整化**：补齐 CSR、CA 签发、PFX、证书链、HTTPS 检测、开发工具六大能力，
> 并接线 v0.1 遗留的基础能力（扩展字段、PFX 转换等），形成完整工具闭环。
>
> 版本定义：v0.1（基础，已交付）→ **v0.2（核心功能完整化，进行中）** → v1.x（浏览器本地运算与扩展，未来）。
>
> 更新日期：2026-08-23

## 范围

### 纳入本版本

**v0.1 遗留基础能力接线**（Core 已就绪、Api 请求模型已定义但未接线）

- CSR 生成支持扩展字段（SAN / KU / EKU / CRLDP）
- CSR 解析输出扩展详情（当前返回空字典）
- 自签名证书支持扩展字段（KU / EKU / SAN / 序列号）
- CA 三种签发模式接线扩展字段（sign-csr / sign-publickey / sign-generate）
- 证书格式转换补齐 PFX（PEM / DER / PFX 互转）

**六大新功能**

- CSR 完整支持（生成含扩展 / 解析 / 验证页面）
- CA 签发证书三种模式（CSR 签发 / 公钥签发 / 直接生成）
- PFX / PKCS#12 支持（合成 / 提取 / 密码保护）
- 证书链构建与验证（Core PKIX 升级）
- HTTPS 证书在线检测与提取
- 开发工具集（JWT / 哈希 / 编解码 / UUID）

**工程**

- 新增 `tests/Crypto.Utils.Api.Tests`

### 不纳入本版本（见后续版本）

- **Browser 本地运算**、SM 浏览器端 WASM → [v1.1](../v1.x/README.md)
- CRL 完整页面、批量操作、OCSP、DNS / HTTP 工具、Docker 部署、工程优化 → [v1.x](../v1.x/README.md)
